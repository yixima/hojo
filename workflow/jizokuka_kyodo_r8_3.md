→ **申請書を書く前に、主催者の出展申込開始時期を一次情報で確認すること。**

### ①謝金の注3 —— ブラッシュアップの形を縛る

> 全参画事業者への指導・助言ではない**個別指導、個別商品開発は補助対象外**。

「作り手ごとに専門家をつけて商品を直す」という一番やりたい形が、そのままでは通らない。
**全参画事業者が同席する合同講評会**の形にし、その場で個別フィードバックを行う設計にする。

### 参画事業者の法人格 —— 産地組合は参画できない

**参画事業者になれない**: 一般社団/財団法人、公益社団/財団法人、NPO法人、**協同組合等の組合（企業組合・協業組合を除く）**、医療法人、宗教法人、学校法人、農事組合法人、社会福祉法人、任意団体、士業のうち医師・歯科医師・助産師、系統出荷のみの個人農業者

**なれる**: 株式会社・合名・合資・合同会社・特例有限会社・企業組合・協業組合・士業法人、**個人事業主（商工業者）**

→ 伝統工芸の**産地組合そのものは参画できない。組合を窓口に、傘下の個社・個人事業主を集める**形にする。

### 小規模事業者の従業員数

- 商業・サービス業（宿泊業・娯楽業を除く）… 常時使用する従業員 **5人以下**
- サービス業のうち宿泊業・娯楽業 … **20人以下**
- **製造業その他 … 20人以下**（工芸の作り手はここ。網は広い）

### その他の要件（参画事業者）
- 資本金5億円以上の法人に直接・間接に100%保有されていない
- 直近3年の課税所得の年平均が15億円以下
- **当社と資本関係がない**
- 一つの公募回で複数の補助事業に参画していない

### 対象外条項（全文の要旨）
- 申請者**自社**の販路開拓のための事業
- 参画事業者の販路開拓につながらない事業
- **補助金活用の有無に限らず過去実施した事業と同様の事業**
- 「地域おこし」「業界支援」「観光PR」化したもの
- 参画事業者への「個別支援」化したもの
- 参画事業者が終始直接関与せず、当社や委託先が代わりに営業・販売する事業
- 申請者・委託先の間で**補助金が還流する仕組み**
- 国の他の補助金と同一・類似内容

## 3. 取組の選択（3類型のうちどれを取るか）

| 類型 | 評価指標 | 判定 |
|---|---|---|
| （1）展示会・商談会 | ①新規リーチ数 ②商談総合計数 ③新規取引先合計数 | **採る** |
| （2）催事販売 | ①来場者数 ②営業効率（期間売上÷総経費×100） | **採る** |
| （3）販売拠点構築 | ①売上合計額 ②営業効率 | **見送る**（1拠点90日以上稼働が必要／⑥出展費が使えない） |

**（1）＋（2）の2取組で申請する。**
複数取組でも補助上限は3,000万円のまま。**各取組にそれぞれ10者以上が必要だが、参画事業者の重複は可**なので、同じ10者が両方に出ればよい。

これが効くのは、**同じ商品をBtoB（商談）とBtoC（実売）の両方の指標で測れる**ため。
「バイヤーには刺さるが客には売れない」「客には売れるがロットが合わない」を、
1回の渡航で切り分けられる。過去の単発出展では取れなかったデータになる。

## 4. 「過去実施した事業と同様の事業」をどう外すか

これが生島様の最大の論点。**外せる。** 根拠は審査の視点そのものにある。

> ⚫ 申請者が**過去に実施した類似事業と比べて発展性はあるか**。（P.13）

つまり制度は「類似領域での申請」を否定していない。**発展していないもの**を否定している。

### 過去の当社事業と、本事業の差

| | 過去（JAPAN EXPO WABI SABI 2011〜／東京手仕事 MAISON&OBJET 2023-25） | 本事業 |
|---|---|---|
| 誰が出展者を選ぶか | **発注者（自治体・公社）が選定** | **当社が主体的に選定** |
| 事前ブラッシュアップ | 発注者側の別事業。当社の契約範囲外 | **当社の責任範囲に含む（合同講評会）** |
| 出展 | あり | あり |
| 事後ブラッシュアップ | なし | **現地の反応を持ち帰り再講評** |
| 終了後フォロー | 契約期間で終了 | **5年間。越境EC「WABI SABI STORE」を無償開放** |
| 測定 | 商談件数の報告のみ | **BtoB3指標＋BtoC2指標の二重測定** |
| 当社の立場 | **出展代行（機会提供）** | **ワンストップ支援機関** |

書き方の要点は、過去実績を隠さないこと。むしろ
**「16都市・91展示会・出展者3,611者・成約率12.2%（2025年3月時点）」を根拠数値として出し、
その実績があるからこの目標値を置ける**と積算根拠に使う。
公募要領は評価指標について「**過去の取組実績等をもととした根拠のある数値で設定すること**」と
繰り返し要求している（P.4-5）。当社は数少ない「その数値を持っている申請者」である。

### 同時に踏んではいけない地雷

- **WABI SABI STORE（自社越境EC）に補助金を充てない。**
  充てると「申請者自身の販路開拓」「補助金の還流」の両方に当たる恐れがある。
  **無償の継続支援チャネルとして提供する**と書く。
  これで「本事業終了後に支援継続できる体制が整えられているか」（審査の視点）を
  費用ゼロで満たせる。**リスクを加点に変える唯一の書き方。**
- **「日本文化の海外PR」に見せない。** 対象外条項の「観光PR」「地域おこし」に触れる。
  主語は常に**参画事業者の売上と新規取引先**に置く。
- **事業の多くを外注しない。** 審査の視点に
  「委託先等が主となって補助事業計画を策定していないか。事業の多くを委託するスキームとなっていないか」
  とある。当社はパリ在住社員2名を擁するので、**現地運営を自社で持つ**ことが差別化になる。

## 6. 予算フレーム（10者・3,000万円を狙う場合の型）

制約は2つだけ。

1. **定額区分だけの申請は不可** → ③④⑤⑥⑧のいずれかを必ず入れる（自然に入る）
2. **⑩委託・外注費 ≦（①+②+⑦+⑨+⑩）× 1/2**

海外案件は通訳・翻訳・国際輸送が膨らむため、**⑩が2の制約に当たりやすい。**
①謝金・②当社旅費・⑨印刷製本を先に積んで分母を確保してから⑩を決める、という順で組む。

## 10. 決めていただきたいこと

1. **GビズIDプライムを保有しているか。保有していれば有効期限はいつか。**
2. **参画事業者は10者（上限3,000万円）を狙うか、5〜9者（2,000万円）で確実に行くか。**
   10者に届かない見込みなら、最初から5者設計にしたほうが安全。
   実績報告時に申請時の者数を下回ると**補助金は1円も支払われない**（P.11 注意事項⑥）。
3. **様式4を依頼する自治体はどこにするか。**（熊本県／岩手県／東京都 のいずれか、または別）
4. **対象展示会はどれにするか。**（当社が申込時期を確認します）
