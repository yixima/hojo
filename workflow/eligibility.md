# 適合判定ロジック

一般社団法人ジャパンプロモーションが、その公募に **実際に応募できるか** を判定する基準。
`profile/company-profile.yaml` を参照しながら適用する。

## 判定は3段階

```
[1] 足切り判定 → 応募不可なら即除外
        ↓
[2] 応募形態の判定 → 単独／共同／支援側 のどれで出せるか
        ↓
[3] スコアリング → S / A / B / C に格付け
```

---

## [1] 足切り判定

以下のいずれかに該当したら **除外**（レポートに載せない）。

| # | 条件 | 判定 |
|---|---|---|
| 1 | 予定価格（補助金は補助上限額）が **500万円未満** | 除外 |
| 2 | 応募締切が **既に過ぎている** | 除外 |
| 3 | `keywords.yaml` の `exclude` が案件の主題である | 除外 |
| 4 | 応募資格が **特定の地域に本店を有する事業者に限る** で、東京都渋谷区が該当しない | 除外 |
| 5 | 応募資格が **個人・大学・研究機関に限る** | 除外 |

### 注意：予定価格が非公開の場合

企画競争では公告段階で予定価格を伏せる案件が多い。**この場合は金額を理由に除外しない。**
「予定価格非公開」と明記したうえでレポートに載せ、業務規模（実施期間・想定人員・
対象国数）から概算を推定して併記する。

---

## [2] 応募形態の判定

**ここが最も重要。** 一般社団法人という法人格が理由で単独応募できない案件でも、
別の形で関与できることが多い。

### 2-1. 単独応募が可能か

公募要領の「応募資格」を読み、以下を確認する。

| 記載パターン | 単独応募 |
|---|---|
| 「法人格を有する団体」「法人」とのみ記載 | **可** |
| 「一般社団法人」が明示的に含まれる | **可** |
| 「中小企業者（会社および個人）」に限定 | **不可** → 2-2 / 2-3 へ |
| 「中小企業者等」で、「等」に非営利法人を含むと注記あり | **可** |
| 「みなし大企業を除く中小企業者」 | 要確認。一般社団法人は中小企業基本法の「会社」に該当しないため通常は不可 |

### 2-2. コンソーシアム共同申請が可能か（生島様の確認済み方針）

「共同申請可」「コンソーシアム形式可」「幹事法人＋構成員」の記載があれば候補に含める。
その際、**どの法人と組めば要件を満たせるか**をレポートに書く。想定パートナー：

- **SUS ENIS（パリ・Maison Wa 運営、代表 塩川嘉章氏）** — フランス現地法人。
  伝統的工芸品産業振興協会パリショールーム運営、複数県のテストマーケティング実績あり
- **SHIBUYA INTERNATIONAL** — 在仏。欧州販路開拓・バイヤー集客
- **株式会社デアイ** — MAISON&OBJET 日本事務局
- 出展を希望する国内の伝統工芸事業者（コンソーシアム構成員として）

### 2-3. 出展事業者の支援側として関与できるか（生島様の確認済み方針）

補助を受けるのが中小企業・工芸事業者で、御社が**その事業の実施を担う**形。
JAPANブランド育成支援等事業、TAKUMI NEXT、各県の海外展開補助金などが該当する。

この場合、公募そのものは御社が応募するものではないため、レポートでは
**「営業機会」区分**として別掲する。補助金の採択事業者リストが公表される案件は、
採択後に営業先リストとして使える旨も記載する。

### 2-4. 自治体・公益法人からの受託

生島様は選択肢としてこれを選ばれなかったが、**過去実績（熊本県・岩手県・
東京都中小企業振興公社）はまさにこの型である。** 完全には除外せず、
優先度を1段下げて掲載する。次回の打ち合わせで扱いを再確認すること。

## [3] 入札参加資格の扱い

資格には**2種類ある。混同しないこと。**

### 3-1. 全省庁統一資格（国の機関向け）

**2026年8月現在、申請提出済み・取得手続き中。**

国の機関の企画競争・入札は、参加要件に「令和8・9年度全省庁統一資格（役務の提供等）の
A・B・C・D等級を有すること」と書かれているものが多い。

| 状況 | 扱い |
|---|---|
| 資格要件の記載がない（自治体・公益法人案件に多い） | 通常どおり掲載 |
| 資格が必要で、**取得が締切に間に合う** | 「要資格取得」フラグ付きで掲載。残日数を併記 |
| 資格が必要で、締切までに間に合わない | 「今回は不可」として別掲。**除外はしない**（翌年度の同一案件を狙うため） |

実例：文化庁「無形文化遺産保護条約に係る国際動向調査事業委託」（2026年9月4日締切）は
「文部科学省競争参加資格（全省庁統一資格）において令和8年度に『役務の提供等』の
A、B、C又はD等級に格付けされている者」が要件で、未取得のため応募できなかった。

### 3-2. 都道府県・市町村ごとの入札参加資格（自治体向け）

**全省庁統一資格とはまったく別の制度で、自治体ごとに個別の登録が必要。**
これを見落とすと、適合すると判断した案件が応募段階で弾かれる。

実例：わかやま産業振興財団「集団出展ブース装飾委託業務【LIFE×DESIGN 2027】」は、
業務内容（県ブースの装飾デザイン・設営・施工・撤去）が御社の主力と完全に一致するが、
参加資格に以下が課されている。

> 和歌山県役務の提供等の契約に係る入札参加資格に関する要綱に基づき、競争入札参加資格者
> 名簿の営業種目の大分類が「10 企画・広告・手配」、小分類が「4 大会・イベント企画運営」
> に登載されている者

**判定手順**：自治体案件を見つけたら、公募要領の参加資格欄で「競争入札参加資格者名簿」
「入札参加資格」の記載を必ず確認する。記載があれば、

1. 当該自治体の資格を保有しているか（`profile/company-profile.yaml` の
   `qualifications` を参照。現在は東京都以外ほぼ未確認）
2. 未保有なら、**随時申請を受け付けているか**（多くの自治体は年1〜2回の定期受付だが、
   随時受付の自治体もある）
3. 締切までに間に合うか

を確認し、間に合わなければ「今回は不可・翌年度に向けて資格取得」としてレポートに残す。

**戦略的示唆**：御社が繰り返し狙う自治体（東京都・熊本県・岩手県・山形県・京都府・
和歌山県など）については、**案件が出る前に入札参加資格を取得しておくべき。**
これが最も費用対効果の高い先行投資になる。

## [3-補] 全省庁統一資格の詳細

**2026年8月現在、御社は申請中で未取得。**

国の機関の企画競争・入札は、参加要件に「令和8・9年度全省庁統一資格（役務の提供等）
の A・B・C・D 等級を有すること」と書かれているものが多い。

| 状況 | 扱い |
|---|---|
| 資格要件の記載がない（自治体・公益法人案件に多い） | 通常どおり掲載 |
| 資格が必要で、**申請受付期間中に間に合う** | 「要資格取得」フラグ付きで掲載。取得手続きの残日数を併記 |
| 資格が必要で、締切までに間に合わない | 「今回は不可」として別掲。**除外はしない**（翌年度の同一案件を狙うため） |

全省庁統一資格は**随時申請を受け付けており**、電子申請なら概ね数日〜2週間程度で
資格審査結果通知書が発行される。締切まで3週間以上あれば間に合う可能性が高いが、
案件ごとに「申請書提出時点で資格を有すること」か「契約時までに取得すればよいか」が
異なるため、公募要領の記載を必ず確認する。

## [4] スコアリング

`keywords.yaml` との一致度と、実績要件の充足度で格付けする。

| 格付 | 条件 |
|---|---|
| **S** | 海外での工芸品・日本文化のプロモーション事業そのもの。過去の受託実績と業務内容がほぼ同一。単独応募可 |
| **A** | core のカテゴリに2つ以上該当し、実績要件を満たせる。単独または共同で応募可 |
| **B** | core に1つ該当。実績要件は満たせるが、業務内容に未経験の領域を含む |
| **C** | 関連はあるが主戦場ではない。または資格・法人格の制約で応募形態に工夫が必要 |

### 加点要素

- `regions.strong` の地域が対象（フランス・欧州・ドバイ・台湾・スペイン等）：**+1ランク**
- 過去の発注元と同一機関（東京都中小企業振興公社、熊本県、岩手県、経産省、VIPO等）：**+1ランク**
- 実施内容に「展示会出展」「パビリオン運営」「バイヤー商談」が含まれる：**+1ランク**

### 減点要素

- 全省庁統一資格が必須で、締切まで3週間未満：**-1ランク**
- 履行場所が国内のみで、海外要素が一切ない：**-1ランク**
- 応募実績のない分野（システム開発、調査研究のみ等）：**-1ランク**

## [5] 実績要件のチェック

多くの企画競争は「過去◯年以内に同種業務の実績を有すること」を求める。
御社が主張できる実績は以下（`profile/company-profile.yaml` の `public_sector_contracts`）。

| 求められがちな実績要件 | 充足できる実績 |
|---|---|
| 海外展示会の出展・運営受託 | 東京手仕事 MAISON&OBJET 2025（4,098万円）、WORLD ART DUBAI 2023、JAPAN EXPO WABI SABI |
| 伝統工芸品の海外プロモーション | 上記すべて。16都市91回のうち49回が伝統工芸品 |
| 自治体からの受託 | 熊本県（2016-2024）、岩手県（2019）、東京都・JOC（2019） |
| 国の機関からの受託 | 経済産業省 COOL JAPAN WORLD TRIAL（2013）、VIPO J-LOP（2016-2018） |
| 一定金額以上の契約履行 | 40,986,000円（税込）の履行実績 |
| 海外現地体制 | パリ在住社員2名、現地外注パートナー複数 |
| 情報セキュリティ体制 | UTM（Check Point CP1530WIFI）、Defender + Kaspersky の二重対策、アクセス制限規程 |

実績要件を満たせない場合は、レポートに **何が足りないか** を明記する。
