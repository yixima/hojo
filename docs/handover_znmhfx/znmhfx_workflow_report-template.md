# 週次レポートの形式

Gmail 本文と Drive 保存用の両方で、この形式を使う。

---

## 件名

```
【公募レポート】2026年8月24日 新規5件（うちS格1件）
```

新規0件のときは `新規0件（該当なし）`。

---

## 本文の構成

### 1. 冒頭サマリー（3行以内）

```
今週の新規該当は5件です。うち即応が必要なものが1件あります。
伝統的工芸品産業振興協会の海外テストマーケティング業務が締切6日後です。
既報案件では、東京都中小企業振興公社の1件が締切3日後に迫っています。
```

数字の羅列ではなく、**何を今すぐ判断すべきか**を先に書く。

### 2. 至急対応（締切7日未満のもののみ。無ければこの節を省く）

### 3. 新規案件

格付の高い順に並べる。1件あたりの書式：

```markdown
#### [S] 2026／令和8年度 海外における伝統的工芸品テストマーケティング業務

| | |
|---|---|
| 発注機関 | 一般財団法人 伝統的工芸品産業振興協会 |
| 種別 | 企画提案募集 |
| 締切 | 2026年9月15日 17:00（**残り22日**） |
| 予定価格 | 非公開（過去実績から2,000〜3,000万円規模と推定） |
| 履行期間 | 2026年10月〜2027年3月 |
| 応募形態 | **単独応募可** |
| 全省庁統一資格 | 不要 |

**業務内容**
欧州および東アジアを中心に、伝統的工芸品の受容性・購買傾向を探るテストマーケティングを実施する。

**なぜ御社に適合するか**
- 同協会のパリショールーム運営に関わったSUS ENISとの連携実績がある
- 令和4年度「東京手仕事」WORLD ART DUBAI、令和4〜5年度JAPAN EXPOで同種業務を受託済み
- 実績要件「海外での工芸品プロモーション業務の経験」を16都市91回の実績で充足

**懸念・確認事項**
- 公募要領○ページに「過去3年以内に同種業務を単独で受託した実績」とあり、
  東京手仕事の受託年度が要件期間に入るか要確認

**リンク** https://...
```

### 4. 営業機会（御社が応募するのではなく、出展事業者向けの補助金）

採択されれば御社の顧客になり得る補助金は、ここに別掲する。

```markdown
- **JAPANブランド育成支援等事業**（中小機構）締切 2026年10月2日
  → 採択事業者は海外展示会出展を計画する。採択発表後に営業リストとして活用可能。
```

### 5. 今回は応募できないが記録しておくもの

全省庁統一資格が間に合わない案件など。**翌年度に同じ公募が出る**ため記録する。

### 6. 既報案件のリマインド

締切が7日以内に迫っている、状態が「新規」「検討中」のもの。

### 7. 巡回範囲の記録（末尾に小さく）

```
確認したソース: 優先度A 6件 / WebSearch 14クエリ
ネットワーク制限: なし
次回実行: 2026年8月31日
```

## 案件リスト（レポートとは別に毎回作る）

本テンプレートはレポート本文の形式。これとは別に、その回の案件一覧を
`data/cases/cases_YYYYMMDD.csv` として作り、一覧アーティファクトとして公開する。
項目の定義は `workflow/case-list-schema.md`。

レポートは**なぜそう判定したか**を書く文書、案件リストは**何がいつまでにあるか**を
一目で見る表。役割が違うので、片方をもう片方の要約にしない。

---

## 書き方の原則

- **判定の根拠を必ず書く。** 「適合します」だけでは生島様が検証できない
- **不確かなことは不確かと書く。** 予定価格の推定値は推定と明示する
- **懸念事項を省かない。** 応募できない可能性がある要件は必ず書く
- 公募要領を読めていない案件は、**「未読・検索結果のみ」と明記する**
