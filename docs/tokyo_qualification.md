# 東京都の競争入札参加資格を取る

作成：2026-08-28（`bin/today.sh` で取得）

---

## なぜ今なのか

**東京都で、大規模な全国イベントが2年連続で開催される。**

| 年度 | イベント | 決定 |
|---|---|---|
| 2027年度 | 第42回国民文化祭／第27回全国障害者芸術・文化祭 | 2026-05-11 |
| 2028年度 | ねんりんピックChõju東京2028（11月3〜6日） | 決定済 |

いずれも開会式・閉会式の企画運営、会場設営、催事、広報の発注を伴う。
当社の中核そのもので、しかも地元である。
発注は2026年度後半から2028年にかけて継続的に出る。

**一度資格を取れば、2年分の案件すべてに応募できる。**
資格がなければ、公告を見ても応募できない。

## 東京都の資格は2種類ある。混同しないこと

| | 東京都電子調達システム | 東京電子自治体共同運営 電子調達サービス |
|---|---|---|
| 対象 | **東京都各局**が発注する物品・委託等 | 東京都内の**区市町村等**の団体 |
| URL | 都庁 財政ページから入る | https://www.e-tokyo.lg.jp/ |
| 有効期間 | 定期受付なら**2年間**（次年度から） | 審査基準日（決算日）から**1年8か月**。事業者ごとに異なる |
| 受付 | **定期受付（2年に1度）と随時受付** | 継続申請は決算月に応じて毎月 |

**国民文化祭とねんりんピックの発注元は東京都（生活文化スポーツ局・福祉局）
なので、必要なのは前者＝東京都電子調達システムの資格である。**

区市町村の案件（千代田区・渋谷区など）を狙うなら後者も要る。
渋谷区は当社の所在地なので、「市内業者限定」に相当する
区内業者限定の案件に応募できる立場にある。**こちらも取る価値がある。**

## 手続きの流れ（東京都電子調達システム）

1. **電子証明書を購入する** ← ここに時間がかかる
   インターネット経由の申請に必須。民間の認証局から購入する。
   発行まで日数を要するため、**これを最初に始める。**
2. パソコン・ソフトウェアの準備（電子証明書を利用するための設定）
3. 電子調達システムから競争入札参加資格審査を申請する
4. 審査 → 競争入札参加有資格者名簿に登載

### 受付の種類

- **定期受付** — 2年に1度。申請すると**次年度から2年間**有効。
  令和7・8年度分は令和6年10月〜11月に受付が行われた
  （一般（個人・法人）は11月1日まで、事業協同組合等は12月16〜20日）。
  **次は令和9・10年度分。時期からみて2026年秋に来る可能性が高い。**
  これがそのまま2027年度の国民文化祭・2028年度のねんりんピックをカバーする。
- **随時受付** — いつでも受け付けている。
  **定期受付を待つ必要はない。**

### 問い合わせ先

東京都財務局 契約第二課 03-5388-2632

## 申請する種目

他自治体の同種案件が求めていた種目から、次が該当すると見られる。
**申請前に東京都の種目一覧で正確な名称を確認すること。**

| 種目（推定） | 根拠 |
|---|---|
| イベント企画運営等 | 横浜市の賑わい創出・催事企画運営・横断幕管理の案件が要求 |
| 広告 | 横浜市 市営バスラッピング広告の案件が要求 |
| 催事・展示装飾 | 千葉市の業種・種目が「広告・催事」 |
| 各種調査企画 | 横浜市の賑わい創出業務が要求 |

千葉市は「委託／広告・催事」、横浜市は「イベント企画運営等」という
呼び方をしていた。**自治体ごとに種目の名称が違う。**

## 他県の資格も、狙う県から順に

当社が繰り返し狙う発注者のある県。**公告を待たずに取る。**

| 県 | 理由 |
|---|---|
| 和歌山県 | LIFE×DESIGN ブース装飾（参加資格に明記・条項なし） |
| 山口県 | やまぐち産業振興財団が年6〜7回の装飾委託 |
| 京都府 | 京都産業21がSEMICON・SXSW等の装飾等業務 |
| 静岡県 | 産業振興財団が年4本以上の県ブース設営等業務 |
| 兵庫県 | ひょうご産業活性化センターのエコプロ県ブース装飾 |
| 群馬県 | FOODEX JAPAN 県ブース装飾設営、国スポ2029 |
| 大阪府 | 大阪産業局のクリエイター博覧会・TENKA！ |
| 宮崎県 | 国スポ2027、装飾・設営案件を年5件 |

**ただし「又は契約締結時までに資格を取得する見込であること」という
条項がある案件は、資格がなくても応募できる**（栃木県の例）。
参加資格の欄は最後まで読むこと。詳細は `workflow/eligibility.md` [4]。
