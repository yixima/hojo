# ビジネスチャンス・ナビの事業者登録

作成：2026-08-28（`bin/today.sh` で取得）

---

## なぜ必要か

**東京都の外郭団体の電子入札に参加するには、ここへの登録が要る。**

公社FAQの原文（https://www.chancenavi.jp/faq_cnavi/）

> 「ビジネスチャンス・ナビ」に登録することにより、
> **①都外郭団体などの電子入札へ参加**、②民間発注案件の掲載や、
> 掲載された案件への受注申込み、③官公庁等の入札案件を一元的に閲覧、
> などが可能となります。

東京都中小企業振興公社は都の外郭団体である。
**御社が令和7年度に4,098万円で受注した「東京手仕事」MAISON & OBJET
出展事業の後継案件も、ここに出る。**

運営：公益財団法人東京都中小企業振興公社
サイト：https://www.chancenavi.jp/

---

## 誰が登録できるか

FAQの原文

> 都内、及び**全国の民間企業**が利用することができます。
> **企業規模や業種は問いません。**
> 店舗や事業所、部署、課などの単位でご登録いただくことも可能です。
> 新規利用申込手続き時に「ビジネスチャンス・ナビ利用規約」に
> 同意していただく必要があります。

**利用は無料。** 一般社団法人である御社も対象になる。
（法人格による制限の記載は見当たらなかったが、申込時に確認すること。）

## 手順

| | |
|---|---|
| 新規利用登録 | https://www.chancenavi.jp/bcn/ |
| ご利用ガイド | https://www.chancenavi.jp/help00001/ |
| 操作マニュアル | https://www.chancenavi.jp/manual/ |
| よくある質問 | https://www.chancenavi.jp/faq_cnavi/ |

1. 新規利用登録から申込
2. 利用規約に同意
3. 企業情報・申請者情報を入力
4. 事務局の審査
5. 登録完了 → マイページが使えるようになる

### 審査期間について

**民間の解説サイトには「最大約10営業日」とあったが、公社の一次資料では
確認できなかった。申込前に事務局へ確認すること。**

これが重要な理由は、**公社案件の募集期間が7〜10日しかない**からである。
公告を見てから登録を始めたのでは、審査が終わる前に締切が来る。
**公告を待たずに、いま登録しておく。**

## 登録後にできること（マイページの構成）

ご利用ガイドの目次から読み取れる範囲。

| タブ | 内容 |
|---|---|
| 新着情報 | |
| 発注したい（発注登録管理） | 自社が発注側になる場合 |
| **受注したい（案件を探す）** | 民間発注案件等／**官公庁入札情報（東京都等）** |
| おすすめ案件（案件管理） | |
| お気に入り登録一覧 | |
| 企業、商品検索 | |
| 自社情報設定 | 基本情報・PR情報・商品情報の登録 |

**「官公庁入札情報（東京都等）」ボタンが、当社にとっての入口。**

PR情報と商品情報も登録できる。
御社の実績（16都市91回の展示会、3,611社の出展、東京手仕事の
MAISON & OBJET 出展事業など）を載せておくと、
発注側からの個別商談の打診を受けられる可能性がある。

## 併せて確認すべきこと

- 登録後、**東京都中小企業振興公社の委託案件がマイページに出るか**を確認する。
  出ないなら、案件の種類ごとに別の入口がある可能性がある。
- 公社の「東京手仕事」プロジェクトは、例年**1〜3月に翌年度案件を公告**する。
  令和7年度の MAISON & OBJET 後継案件は2026年3月3日に締め切られていた。
  **次は2027年2月下旬から3月上旬。それまでに登録を済ませておく。**

## 認証情報の置き場所（2026-10-19 に判明した事故）

**2026-10-19、コンテナが作り直され、スクラッチパッドに置いていた認証情報が消えた。**
その日のビジネスチャンス・ナビの巡回は、ログインできずに終わった。

経緯：
- 2026-10-13、生島様から `CN_USER` / `CN_PASS` を会話で頂いた
- リポジトリは公開なので書けない（CLAUDE.md の禁止事項）。
  そこでセッションのスクラッチパッド（`/tmp/claude-0/.../scratchpad/.cn_env`）に
  chmod 600 で置き、毎回 `. <そのパス> &&` を前置して使っていた
- **5日間は動いた。コンテナが作り直された瞬間に消えた。**
  リポジトリも古い commit に戻っており、手順2の `git fetch && git merge` で復旧した。
  **スクラッチパッドには復旧する手段が無い。**

**正しい置き場所は、環境（Environment）の設定である。**
セッションのタイトルバーのクラウド環境メニュー →「編集」→
**Network secrets（更新前のアプリでは「API credentials」）**の節、
その節が無ければ**環境変数**として、次の2つを登録する。

```
CN_USER   （ビジネスチャンス・ナビのログインID）
CN_PASS   （同パスワード）
```

- **登録後に開く新しいセッションから有効になる。**
- **会話に貼り付けていただく必要はない。**むしろ貼らないほうがよい
  （会話は引き継ぎに残り、引き継ぎは事故の元になる）
- 道具は `os.environ` からしか読まない（`bin/chancenavi.py`）。
  未設定なら「**設定されていないため確認できなかった**」と印字して止まる。
  **黙って飛ばさない**（回帰テスト `bin/test_watchdog.py` が走査している）
