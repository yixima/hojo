# 引き継ぎ書：公募案件（補助金・企画競争）探索ワークフロー

最終更新: 2026-08-19
担当者: 生島 儀尊 様（一般社団法人ジャパンプロモーション 代表理事 / iximay@gmail.com）
作業ブランチ: `claude/public-bid-search-workflow-uzj3te`

## このプロジェクトの目的

一般社団法人ジャパンプロモーションが**申請・提案可能な公募案件**を継続的に探し出し、
生島様に届けるワークフローを構築する。対象は以下の2種類。

- 補助金
- 企画競争／企画提案（公募型プロポーザル）

## 決定済みの要件（本人確認済み・8件）

| # | 項目 | 決定内容 |
|---|---|---|
| 1 | プロファイル入手元 | Google Drive の一次資料から抽出済み（`profile/company-profile.yaml`） |
| 2 | 発注元の範囲 | **全国・全発注元**（国・自治体・基金・公益法人などを広く） |
| 3 | 事業ドメイン | 海外展開支援／伝統工芸品の海外プロモーション／自治体のシティプロモーション／インバウンド |
| 4 | 全省庁統一資格 | **現在申請中**。国の案件は「資格取得後なら応募可」として別枠で提示する |
| 5 | 実行頻度 | **週次** |
| 6 | 届け先 | **Gmail で送信 ＋ Google Drive に一覧表を蓄積**（重複検出は蓄積側で行う） |
| 7 | 案件規模の下限 | **予定価格（補助金は上限額）500万円以上**。海外出展は渡航費・国際輸送・施工で費用が嵩むため |
| 8 | 応募主体 | 単独に加えて **(a) 企業・団体とのコンソーシアム共同申請**、**(b) 出展事業者の支援側としての関与** も可 |

補足: 「自治体・公益法人との連携／受託」は選択肢に含めたが選ばれなかった。ただし
過去実績（熊本県・岩手県・東京都中小企業振興公社）は明確にこの型なので、
判定ロジックから完全には除外せず、優先度を下げて扱うのが妥当と考えられる。
実装前に生島様へ再確認すること。

## 未確認・保留の項目

- 基本財産、年間収入規模、正確な従業員数（提案書記載の社員は5名以上、うちパリ在住2名）
- 全省庁統一資格の申請中の等級・営業品目
- 東京都の入札参加資格の有無
- インボイス登録の有無
- 締切までのリードタイム下限（何日前までの案件を「応募可能」とみなすか）
- HPの最新実績値（下記「既知の制約」を参照）

## 既知の制約

### 1. 御社HPがネットワークポリシーでブロックされている

`www.japanpromotion.org` はクラウド環境の egress ポリシーで拒否される（403）。
そのためHP掲載の最新実績値が読めていない。`profile/company-profile.yaml` の
`scale:` は提案書（2025年3月時点）の値、`latest_unverified:` は Web検索の
要約経由で得た**未確認の参考値**。混同しないこと。

**解決策**: claude.ai/code の環境セレクタ（メッセージ入力欄の上にある雲アイコン）から
ネットワークアクセスを `Custom` にし、`japanpromotion.org` と `*.japanpromotion.org`
を許可ドメインに追加する。「一般的なパッケージマネージャーのデフォルトリストも含める」
のチェックは必ずオンにする（外すと npm/PyPI/GitHub が遮断される）。
設定はセッション開始時に適用されるため、新しいセッションが必要。

### 2. Google Drive コネクタの権限

当初「Claudeが作成したファイルのみ」のスコープになっており、生島様がアップロードした
ファイルが一切見えなかった（ファイルID直指定でも404）。**再接続で解決済み**。
同様の症状が再発した場合は、コネクタを切断→再接続し、権限画面で
「すべてのファイル」系の項目をオンにすること。

### 3. claude.ai プロジェクト「自治体企画提案」

Drive の README によれば、判断の根拠となる文書の正本は claude.ai のプロジェクト
「自治体企画提案」側に置かれている。**そちらはセッションからは読めない。**
