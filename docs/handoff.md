## このプロジェクトの目的

一般社団法人ジャパンプロモーションが**申請・提案可能な公募案件**を継続的に探し出し、
生島様に届けるワークフローを構築する。対象は以下の2種類。

- 補助金
- 企画競争／企画提案（公募型プロポーザル）

## 決定済みの要件（本人確認済み・8件）

| # | 項目 | 決定内容 |
|---|---|---|
| 1 | プロファイル入手元 | Google Drive の一次資料から抽出済み（`profile/company-profile.yaml`） |

### 小規模事業者持続化補助金＜共同・協業型＞第3回（公募要領 第6版 全47ページを精読）

| 論点 | 結論 |
|---|---|
| 一般社団法人は「地域振興等機関」として申請できるか | **できる**。応募資格は「法人」とのみ規定（P.6）、定義⑤「地域の企業の販路開拓につながる支援を事業として行っている法人」に該当（P.1）。QA A2 が排除するのは個人事業主＝法人格の不存在であって法人格の種類ではない |
| 補助上限額 | **3,000万円**（参画事業者10者以上）／**2,000万円**（5〜9者）。P.8 |
| 海外展開は対象事業か | **対象**。⑥展示会等出展費が「**国内外**で開催される展示会・商談会、販売会」を明記（P.16）。⑩注4 が海外での通訳・翻訳費を規定（P.17）。別添2 に【国外旅費】があり、パリ 宿泊38,000円/夜・日当5,400円 |
| 締切 | 2026年9月30日 17:00。Jグランツのみ。**GビズIDプライム必須（取得に数週間）** |

**海外展開で申請する場合の重大な制約**（詳細はレポート参照）
- **国際輸送費の経費区分が存在しない。**（①〜⑩に運搬費・輸送費・通関費がない）→ 事務局への事前確認が必須
- 「テストマーケティング・テスト販売等に係る経費」は補助対象外（P.19）→ 岩手県案件型の建付けは通らない
- 参画事業者自身が渡航・出展する必要がある（代理は「正当な理由」が必要）
- 申請者自身の販路開拓は対象外 → WABI SABI STORE への送客を目的にできない
- 交付決定は実質2027年1月以降 → **狙えるのは2027年春〜秋の展示会**

**注意**: 一般社団法人は「参画事業者」にはなれない（P.2）。これは支援される側の話で、
申請者としての可否とは別。QA A7 も両者の兼任を禁じている。

### tier_a 7組織の巡回結果

現在応募可能な案件は **JETRO 1件（ベオグラード博 日本館運営、締切9/8）** と
**東京都中小企業振興公社 3件**（8/24・8/25・8/26 締切）。伝産協会・CLAIR・中小機構・
国際交流基金は該当なし。中小企業庁は持続化＜共同・協業型＞のみ。

**最重要の発見**: JETRO の入札では、全省庁統一資格が未取得でも
「JETRO 発行の等級確認結果通知書」で代替できる制度がある（ベオグラード博 日本館運営の
場合、等級確認の申請期限は 2026-08-26 17:00）。**統一資格の取得完了を待たずに
JETRO 案件を狙える**ということ。ただし同案件は **Pマークまたは ISMS が参加必須要件**で、
未保有なら要件を満たす法人を主幹事とする共同企業体でしか参加できない。

各組織の巡回のコツは `workflow/sources.yaml` の tier_a 各 note に追記済み。
