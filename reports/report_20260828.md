- **設営等業務／装飾委託業務／ブース企画・設営業務** → 当社が受託者として応募する
- **共同出展企業募集／出展者募集／参加発注企業募集** → 出展する企業向け。当社は対象外

京都産業21の一覧80件のうち、当社が応募できるのは装飾等業務だけである。
混同すると案件数を水増しして報告することになる。

台帳を精査するなかで、**中身が完全に当社の領域なのに応募できない案件**が
いくつも見つかった。格付を付ける前に確認すべきことが3つある。

#### 所在地要件

> 令和8・9年度千葉市入札参加資格者名簿(委託)に登録のある**市内業者**であること。
> （JR千葉駅・モノレール千葉駅連絡通路壁面等装飾業務委託）

当社は渋谷区の法人なので、資格を取っても応募できない。
市区町村案件には「市内業者」「市内に本店」「準市内業者（市内に営業所）」の
区分がある。**準市内業者まで認める案件なら、営業所の設置で参加余地がある。**

**横浜市は本文とは別に「所在地区分」欄を構造化して持っている。**
「指定なし」なら応募可、「市内」なら不可。本文を読まなくても判定できる。
千葉市のように本文を読まないとわからない自治体とは対照的で、
確認方法は自治体ごとに違う。

#### 資格の取得が間に合うか

> 入札参加資格を有するものと決定された者であること。
> **又は契約締結時までに資格を取得する見込であること。**
> （栃木県 観光情報商談会運営等業務）

**この条項があれば、資格を持っていなくても応募できる。**
自治体の入札参加資格は申請から登載まで1〜2か月かかるので、
条項の有無で「公告を見てから間に合うか」が正反対になる。
わかやまのLIFE×DESIGNにはこの条項がなく、取得が前提だった。

**繰り返し狙う県（山口・京都・静岡・兵庫・和歌山・大阪・群馬・東京）の
資格は、公告を待たずに取得しておくこと。**

## 7. 今回わかった取りこぼしの構造

1. **「現在募集中」だけを見ると翌年度事業を全て逃す。**
   GREEN×EXPO の6件はいずれも会期の前年度に公告されていた。

2. **産業支援機関（外郭団体）の発注密度が突出して高い。**
   組織数は61で全体の28%だが、装飾・設営案件の**過半を占める**。
   都道府県本体より外郭団体を優先して巡回すべきである。

3. **巡回間隔が発注の窓より長い。**
   大分県の案件は参加申込期間が9日間しかなかった。
   週次巡回では取りこぼす。**参加申込型の案件は巡回を週2回に上げる必要がある。**

## 8. 自動巡回が不可能な巡回先（手動確認が必要）

全経路（UA・ヘッダ・TLS設定の変更、Chromium／Playwright）を試したうえでの
確定結果。**回避は試みない。** 放置すると分母から静かに欠落するため記録する。

| 対象 | 症状 |
|---|---|
| 岐阜県 `www.pref.gifu.lg.jp` | TLSは成立するがサーバが無応答で切断。データセンターIPからの遮断とみられる |
| 山梨県 `www.pref.yamanashi.jp` | 同上 |
| えひめ産業振興財団 `www.ehime-iinet.or.jp` | 同上（URL自体は正しいことを確認済み） |
| 岡山県産業振興財団 `www.optic.or.jp` | HTTP 423「Security check required」の人間確認画面。明示的なボット対策 |
| 東京都生活文化スポーツ局 | Liferay製SPAで本文が静的HTMLに含まれない。**財務局の入札・契約情報から追う** |
| VIPO | 一覧が静的HTMLに出ない。案件は手動確認 |
| 調達ポータル p-portal | 検索POSTが常に「不正な操作が行われました」。全hidden項目の再現・セッション確立・Referer/Origin付与を試したが同じ。サーバ側で画面遷移状態を検証しており、JSなしでは通らない。実ブラウザは当該ホストへの接続自体がリセットされる |

佐賀は `infosaga.or.jp` がDNSに存在せず、`saga-itc.jp` が正しいURLだった（修正済み）。
p-portalの実害は小さい。国の委託・入札は各省庁の調達情報ページとJETRO入札情報から
取得できており、p-portalはその重複にあたる。

**なお、失敗には3種類あり、混同すると巡回先を静かに失う。**

| 種類 | 症状 | 対処 |
|---|---|---|
| 恒久的な遮断 | 何度やっても同じ形で失敗する | 巡回を諦め、手動確認の対象にする |
| **不安定** | 同じURLが通ったり通らなかったりする | **リトライする。諦めてはいけない** |
| JSレンダリング | HTTP 200だが本文が静的HTMLにない | 別経路を探す |

**岡山県（県庁のほう）を、1回の失敗で「到達不能」と判定しかけた。**
実際は3回リトライすれば通る。取得処理を `bin/fetchlib.py` に集約し、
全スクリプトを**3回リトライ（待ち 1→2→4秒）＋最小サイズ判定**に統一した。
