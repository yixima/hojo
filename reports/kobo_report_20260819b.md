#### 論点① 一般社団法人は「地域振興等機関」として申請できるか → **できます**

根拠は3点あります。

1. **応募資格（P.6「４．応募資格・申請要件」冒頭）**
   > 本事業の対象となる申請者は、次の条件を満たす「**法人**」とする。

   法人格の種類を限定していません。一般社団法人は法人です。

2. **地域振興等機関の定義⑤（P.1）**
   > ⑤地域の企業の販路開拓につながる支援を事業として行っている**法人**
   > ※⑤については申請書記載のこれまでの取り組み内容やその実績・効果等、総合的な
   > （第３者による）審査を行い判断します。

   ①〜④は商工会・商工会議所・中央会・商店街振興組合・事業協同組合と法人類型が
   特定されていますが、**⑤だけは「法人」一般**です。御社は WABI SABI STORE の運営と
   16都市91回の出展支援で「販路開拓につながる支援を事業として行っている」実態があり、
   ⑤に該当すると主張できます。

3. **よくある質問 Q2・Q4**
   > Q2 地域振興等機関に、個人事業主はなることはできるのか。
   > A2 できません。地域振興等機関の定義には個人事業主が該当する項目はございません。

   排除されるのは個人事業主＝法人格がない場合であり、法人格の種類ではありません。

   > Q4 「地域の企業の販路開拓につながる支援を事業として行っている法人」の
   > 「地域とは」どの程度の範囲を指すのか。
   > A4 **地域の範囲については特に制限はございません。**

   Q9 も「参画事業者の地域を限定する必要はございません」としています。
   → **全国から工芸事業者を集めてよい**ということです。御社の全国ネットワークがそのまま使えます。

**ただし注意点が2つあります。**

- **一般社団法人は「参画事業者」にはなれません。** P.2 の参画事業者の範囲では
  「参画事業者とならない者」に一般社団法人が明記されています。これは**支援される側**の
  話で、支援する側（申請者）の要件とは別です。Q7 も「参画事業者と地域振興等機関に
  同一法人がなることはできません」としており、両者が別物であることを裏づけています。
- **⑤該当性について事務局は事前回答しません。** Q1 に「自社判断をしたうえで、申請して
  ください。審査によりますので、事務局にお問い合わせいただいても回答いたしかねます」と
  あります。→ **申請書（様式2-1）でこれまでの支援実績をどこまで具体的に書けるかが
  採否を分けます。** 実績資料.pdf の 3,611社／6,618件／27自治体 はここで使う数字です。

#### 論点② 補助上限額 → **3,000万円（参画10者以上）／2,000万円（5〜9者）**

公募要領 P.8「６．補助上限額及び補助率」より。

| 参画事業者数 | 補助上限額 |
|---|---|
| 10者以上 | 3,000万円 |
| 5者以上9者以下 | 2,000万円 |

補助率は経費区分ごとに異なります（同 P.8）。

| 経費区分 | 補助率 |
|---|---|
| ①謝金 | 定額（＝100%） |
| ②地域振興等機関旅費 | 定額 |
| ③参画事業者旅費 | 2/3以内 |
| ④借料 | 2/3以内 |
| ⑤設営・設計費（内外装費、整備工事等） | 2/3以内 |
| ⑥展示会等出展費 | 2/3以内 |
| ⑦備品費 | 定額 |
| ⑧広報費 | 2/3以内 |
| ⑨印刷製本費 | 定額 |
| ⑩委託・外注費 | 定額（①②⑦⑨⑩の合計の1/2以内が上限） |

**設計上効く制約**
- 定額補助率の経費**のみ**を計上した申請は認められません（P.8）
- 複数の取組（展示会／催事販売／販売拠点構築）で申請する場合、
  **すべての取組に10者以上**参画してはじめて3,000万円（Q27）。1つでも5〜9者なら2,000万円
- 実績報告時に10者（または5者）を下回ると**補助金は支払われません**（P.11 ⑥、Q21）

#### 論点③ 海外展開は対象事業になるか → **なります。要領に明記されています**

3か所に根拠があります。

1. **⑥展示会等出展費（P.16）**
   > **国内外**で開催される展示会・商談会、販売会に参画事業者の商品・製品・サービス等を
   > 出展するために支払われる経費（補助率 2/3以内）

2. **⑩委託・外注費 注4（P.17）**
   > **海外での展示会･商談会､販売会**における通訳､広告物や会議資料等の翻訳に要する
   > 経費は⑩委託・外注費に計上。

3. **別添２「旅費の支給基準について」に【国外旅費】の節がある**（P.24以降）
   国別・都市別の宿泊費上限表が載っています。御社の主戦場では：

   | 都市 | 宿泊費上限（一夜） | 日当 |
   |---|---|---|
   | パリ | 38,000円 | 5,400円 |
   | マドリード | 36,000円 | 5,400円 |
   | バルセロナ | 34,000円 | 5,400円 |
   | ローマ | 30,000円 | 5,400円 |

   > 【国外旅費】※不課税
   > **補助金事務局と協議の上、必要に応じて支出できるものとする。**
   > ・航空賃、鉄道賃、及び船賃は、**エコノミークラス**（普通クラスに相当するもの）による
   > 実費額を支給する。

#### 海外展開で申請する場合の重大な制約（**必ずお読みください**）

対象にはなりますが、**御社の通常の事業の形そのままでは通りません。** 設計変更が要る点を
重い順に挙げます。

1. **国際輸送費の経費区分が存在しません。** 経費区分は①〜⑩の10種類のみで、
   運搬費・輸送費・通関費という区分がありません。⑩委託・外注費での計上可否は要領に
   記載がなく、**事務局への事前確認が必須**です。海外出展では最大級のコストであり、
   ここが認められないと積算が成立しません。**最優先の確認事項です。**
2. **「テストマーケティング・テスト販売等に係る経費」は補助対象外**（P.19「経費として
   計上できないもの」）。岩手県案件のようなテスト販売型の建付けは**そのままでは通りません**。
   「販売拠点構築の取組」の定義（P.5）でも「テストマーケティング、展示会・商談会や催事、
   販売会への出展は販売拠点構築の取組とはなりません」と念押しされています。
3. **参画事業者自身が渡航・出展する必要があります。**
   > ※展示会・商談会は原則参画事業者自らが参加する必要があります。申請者や一部の参画
   > 事業者、営業代行業者等が代理で行う場合は**正当な理由が必要**となります。
   > （正当な理由として認められない場合、補助金のお支払いができません）

   → 小規模事業者5〜10者を実際にパリ等へ連れて行く前提の計画になります。
   参画事業者旅費は2/3補助（自己負担1/3）なので、**事業者側の資金負担をどう説明して
   参画に同意してもらうか**が実務上の最大の山です。
4. **申請者自身の販路開拓は対象外**。要領1ページ目の冒頭に
   > ・本事業は、地域の小規模事業者の販路開拓を支援するものであり、**地域振興等機関
   > （申請者）の販路開拓を支援する事業ではありません。**

   → WABI SABI STORE への送客を目的に見える設計は不可。⑥の注3で
   「補助事業者自身の出展料は補助対象外」とも明記されています。
5. **「地域おこし」「業界支援」「観光PR」とならないよう留意**（P.4）。
   シティプロモーション色を出すと目的外と判断されます。
6. **ビジネスクラス不可／パスポート・ビザ取得料は対象外／商品の仕入れ・販売に直接
   かかる費用は対象外／参画事業者の商品保管費用は対象外**（Q16）。
7. **交付決定日前に出展の本申込みをすると補助対象外**（⑥注1）。
   採択発表が令和8年11月頃、交付決定はそこから1〜2か月 → **実質2027年1月以降**。
   事業期間は令和9年12月10日まで。→ **狙えるのは2027年春〜秋の展示会**です。
   Maison&Objet Paris の1月会期は交付決定に間に合わない可能性が高く、9月会期のほうが安全です。
