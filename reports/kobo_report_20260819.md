## 1. 新規案件

### [S候補] 小規模事業者持続化補助金＜共同・協業型＞ 第3回公募

| | |
|---|---|
| 発注機関 | 中小企業庁（令和6年度補正予算事業） |
| 種別 | 補助金 |
| 申請受付 | 2026年8月14日 〜 **2026年9月30日 17:00**（残り42日） |
| 採択発表 | 2026年11月頃 |
| 事業実施期限 | 交付決定日 〜 2027年12月10日 |
| 補助額・補助率 | **要確認**（公募要領未読） |
| 応募形態 | **支援側＝申請主体**（生島様が選択された形態そのもの） |
| 全省庁統一資格 | 不要（補助金のため） |

**なぜ御社に適合するか**

公募の趣旨が「**地域振興等機関が主体的・中心的な役割を担い、複数の小規模事業者の
商品・サービスの改良やブランディング支援に加えて、販路開拓の機会の提供を行う取り組み**」
とされています。これは御社の事業構造と一致します。

- 「複数の小規模事業者」＝ 出展事業者（2024年実績：411者・2,710品目）
- 「ブランディング支援」＝ カタログ制作、工房取材、ビジュアル演出
- 「販路開拓の機会の提供」＝ 海外展示会への出展、バイヤー商談、WABI SABI STORE

通常の補助金と異なり、**補助を受けるのが支援機関側**なので、一般社団法人という
法人格が障害になりにくい構造です。

**確認が必要な事項（重要）**

1. **「地域振興等機関」の定義に一般社団法人が含まれるか。** ここが最大の関門です。
   商工会・商工会議所・自治体に限定されている可能性があります
2. 補助上限額と補助率（500万円の下限を満たすか）
3. 参画事業者（小規模事業者）を何者集める必要があるか
4. 「地域」の定義。海外展開が対象事業として認められるか

**リンク**

- [共同・協業型 公式サイト](https://r6.kyodokyogyohojokin.info/)

## 4. 構造的な発見（今後の巡回方針に反映）

初回巡回で分かった最も重要なことは、**この分野の公募には強い季節性がある**という点です。

```
 1月 ─ 2月 ─ 3月 ─ 4月 ─ 5月 ─ 6月 ─ 7月 ─ 8月 ─ 9月 ─10月 ─11月 ─12月
 ████████████████████████████████████         ░░░░░░░░░░░░░       ████
 ↑ 翌年度案件の公告・締切が集中する繁忙期        ↑ 端境期        ↑ 再開
```

- **1〜6月**：翌年度（令和9年度）の企画競争・企画提案が集中。ここを取り逃すと1年待ち
- **7〜10月**：端境期。補正予算関連の補助金が散発的に出る（今回の持続化補助金がこれ）
- **11〜12月**：翌年度予算の内示を受けて公告が再開

したがって週次巡回は通年で行いつつ、**12月〜6月は特に密度を上げる**必要があります。
`workflow/runbook.md` にこの方針を追記しました。
