契約能力なし／破産手続開始の決定を受け復権を得ない／暴力団員等／

御社はいずれにも該当しないと思われる。

### 業務実績（**いずれか一方**を満たせばよい）

> **ア** 国、地方公共団体、公益法人その他これらに準ずる団体が発注した、
> **三千人以上**の大規模イベントや展示会、文化芸術催事等にかかる
> **計画策定業務および実施運営業務**の経験

> **イ** 上記アの発注者に限らず、**国際博覧会における民族・伝統芸能などの
> 日本伝統文化発信に資する行催事（公演、パレードなど）**にかかる
> **計画策定業務および実施運営業務**の経験

**アは満たせる見込みが高い。** 東京都（地方公共団体）発注の「東京手仕事」
MAISON & OBJET 出展事業（令和7年度・40,986,000円）は展示会の計画策定と
実施運営を一体で受託したものであり、来場規模も三千人を大きく超える。
契約書の写しを添付できる。

**イには論点がある。** 御社の JAPAN EXPO 公式パビリオン WABI SABI（2011年〜）、
HYPER JAPAN パビリオン MIYABI、WORLD ART DUBAI JAPAN ZONE は
まさに「日本伝統文化発信に資する行催事」だが、要件は
**「国際博覧会における」**と限定している。JAPAN EXPO はBIE公認の国際博覧会ではない。
協会がこれを認めるかで評価点が変わる（後述）。**質問受付で確認すべき論点。**

### 提案内容の内訳（100点）

| | 配点 |
|---|---:|
| ア 博覧会の理念・テーマの具現化と来場者への訴求 | 20 |
| **イ 全国のまつり団体の招聘。実績とネットワークの活用** | **30** |
| ウ 構成案を踏まえた演出とコンセプトの伝達 | 20 |
| **エ 2027年1月以降の実施運営を見据えた人員確保・実施体制・スケジュール・安全計画** | **30** |

**イとエで60点、提案内容の6割を占める。** ここが勝負どころ。

エは「実施計画作成だけでなく、**2027年1月以降の実施運営を見据えた**」と明記されている。
協会は後続の随意契約を前提に見ており、**運営体制の実在性を問うている**。
御社の16都市91回の実施運営実績はここで効く。

### 業務実績（20点）— ここに大きな差がつく

| 評価 | 条件 | 点数（管理技術者・担当技術者 各10点） |
|---|---|---:|
| **A** | **①と②の両方**の経験を有する | 各10点 → **計20点** |
| C | ①または②の**いずれか**の経験を有する | 各6点 → 計12点 |
| E | AにもCにも該当しない | 各2点 → 計4点 |

**参加条件は「いずれか」で足りるが、満点を取るには「両方」が要る。**
差は8点（206点満点中の3.9%）。前述の要件②の解釈がここに直結する。

### 業務遂行能力（40点）— 価格が19%を占める

評価は**他社との相対順位**である。

    1点あたりの費用金額 ＝ 見積金額 ÷（業務実績＋提案内容＋ヒアリング＋WLBの合計点）

- 費用対効果が1番目 → A＝40点
- 2番目 → C＝24点
- 3番目 → E＝8点

**1位と2位で16点、1位と3位で32点の差がつく。** 提案内容ア（20点満点）より重い。
上限1,430万円に対してどこまで積むかは、単なる価格戦略ではなく評価点そのものである。

### ワーク・ライフ・バランス（6点）— 取りに行く価値がある

各項目1点。**該当するものがなければ資料提出は不要**だが、逆に言えば
届出や認定があるだけで加点される。

| くるみんマーク または えるぼしマークの取得 | |
| ユースエール認定の取得 | |
| 障害者雇用（従業員40人未満なら1人以上雇用） | |
| 健康経営銘柄・健康経営優良法人の取得 | |

**上2つは労働局への届出だけで取れる。** 御社は従業員101人未満なので対象になる。
費用はかからず、数日で受付印がもらえる。**2点は同点時に効く。**

## 業務の中身について判明していること

見積書の作成指示から、プロジェクトの構成要素が読み取れる。

- **パレードに「跳人隊（はねとたい）」を編成する**（協会と協議のうえ構成）
  → 青森ねぶた祭の踊り手。まつり団体の招聘が業務の核にある。
- **「令和田楽」の創作**（協会と協議して策定するため見積からは除く）
- **トゥンクトゥンクねぶた1台、協賛ねぶた1台の製作**（同上、見積から除く）

つまり本業務は「ねぶた・田楽を軸に、全国のまつり団体を招聘して
博覧会会期中の催事を組み立てる」計画作成である。
**まつり団体とのネットワークの実在性が評価内容イ（30点）で直接問われる。**

なお業務説明資料は、秘密保持誓約書（参考様式10-1または10-2）を
**9月7日17時までに**提出した者にのみ開示される。
**参加意向申出書と同時に出すこと。** これを出さないと業務の詳細がわからないまま
提案書を書くことになる。
